# Provisioning and Lifecycle Management

## Invariants
1. Private keys are generated and kept exclusively on Android.
2. Device token is generated by the control plane upon first enrollment; only its SHA-256 hash is persisted server-side.
3. If initial gateway provisioning fails, uncommitted device records must be rolled back to avoid stranding the device in a 401 lockout.
4. Key rotation preserves device ID, assigned server, client /32 address, and device token.
5. Old peer is replaced idempotently; on failure, old peer is restored.
