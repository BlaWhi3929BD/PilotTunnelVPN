## 1. Как устроен этот гайд: выбор вашего пути

VPN состоит из двух частей:
1. **Сервер (шлюз и диспетчер):** программа, которая раздаёт интернет и шифрует данные через протокол WireGuard. Ей необходима операционная система **Linux** (так как сетевой модуль WireGuard встроен прямо в ядро Linux).
2. **Клиент (смартфон):** телефон с операционной системой **Android 8.0** или новее.

### Выберите ваш сценарий:

* **Сценарий №1 (Самый популярный в жизни — «Боевой сервер»):**
  У вас есть дешёвый удалённый Linux-сервер (VPS за 200–400 рублей в месяц в Нидерландах, Германии и т.д.), а дома рабочий компьютер (Windows или Linux) и телефон. Вы ставите серверную часть на VPS, а приложение собираете на компьютере и ставите на телефон.
* **Сценарий №2 («Всё на одном компьютере под Linux»):**
  Ваш основной ПК или ноутбук работает на Ubuntu, Debian, Fedora или Arch. Сервер запускается прямо на этом компьютере в одной локальной сети с телефоном.
* **Сценарий №3 («Всё на одном компьютере под Windows»):**
  На вашем ПК установлена Windows 10 или 11. Для серверной части мы включим бесплатную официальную подсистему **WSL2** (Ubuntu внутри Windows за 1 клик), а приложение соберём через Windows.

## Шаг 1: Подготовка инструментов на вашем компьютере

### А. Инструкция для Windows

На Windows нам понадобятся: **Git**, **Java 17 (или Android Studio)** и, если вы хотите запускать сервер локально, **WSL2**.

#### 1. Установка Git
1. Скачайте официальный установщик Git с сайта [git-scm.com](https://git-scm.com/download/win).
2. Запустите скачанный файл, на всех шагах установщика нажимайте «Next» (настройки по умолчанию идеальны).
3. После установки в меню «Пуск» появится программа **Git Bash** — это удобная командная строка.

#### 2. Установка Java 17 (JDK)
Для сборки приложения Android нужна Java версии 17:
1. Скачайте бесплатный дистрибутив Eclipse Temurin JDK 17 с официального сайта: [adoptium.net](https://adoptium.net/temurin/releases/?version=17).
2. Выберите Windows x64 `.msi` установщик.
3. При установке убедитесь, что включена галочка **«Set JAVA_HOME variable»** (Установить переменную JAVA_HOME).

#### 3. Установка инструментов Android (ADB)
1. Скачайте официальный архив platform-tools от Google: [developer.android.com/tools/releases/platform-tools](https://developer.android.com/tools/releases/platform-tools).
2. Распакуйте архив, например, в папку `C:\platform-tools`.
3. Добавьте этот путь в системную переменную `PATH` (или просто открывайте командную строку прямо в этой папке).

#### 4. (Если сервер будет на этом же ПК) Включение WSL2 (Ubuntu на Windows)
1. Откройте меню «Пуск», введите `PowerShell`, нажмите правой кнопкой мыши и выберите **«Запуск от имени администратора»**.
2. Введите команду:
   ```powershell
   wsl --install -d Ubuntu
   ```
3. Перезагрузите компьютер по запросу системы. После перезагрузки откроется окно Ubuntu, где вам предложат придумать логин и пароль.

### Б. Инструкция для Ubuntu / Debian Linux

Откройте терминал (`Ctrl + Alt + T`) и выполните команды:

```bash
# 1. Обновляем списки пакетов
sudo apt update

# 2. Устанавливаем Git, Python и системные утилиты
sudo apt install -y git python3 python3-venv python3-pip openssl curl

# 3. Устанавливаем WireGuard и правила маршрутизации
sudo apt install -y wireguard wireguard-tools iptables

# 4. Устанавливаем Java 17 и утилиту связи с телефоном (adb)
sudo apt install -y openjdk-17-jdk adb
```

Проверим установку Java:
```bash
java -version
```
*(Должно появиться сообщение: `openjdk version "17.0.x"`).*

### В. Инструкция для Fedora / RHEL

Откройте терминал и выполните:

```bash
# 1. Устанавливаем базовые инструменты, Python и Git
sudo dnf install -y git python3 python3-pip openssl curl

# 2. Устанавливаем WireGuard и сетевые инструменты
sudo dnf install -y wireguard-tools iptables iptables-services

# 3. Устанавливаем Java 17 и ADB
sudo dnf install -y java-17-openjdk-devel android-tools
```

### Г. Инструкция для Arch Linux / Manjaro

Откройте терминал и выполните:

```bash
# Устанавливаем все нужные пакеты одной командой
sudo pacman -S --needed git python python-pip wireguard-tools iptables-nft jdk17-openjdk android-tools openssl
```

## Шаг 3: Настройка и запуск серверной части

> 💡 **Примечание:** эти действия выполняются на машине с Linux (на вашем Linux-ПК, на удалённом VPS или внутри WSL2 на Windows).

### 1. Создание виртуального окружения Python
Виртуальное окружение нужно для того, чтобы библиотеки проекта не конфликтовали с системными программами.

В папке `PilotTunnelVPN` выполните:
```bash
# Создаём изолированную папку .venv
python3 -m venv .venv

# Обновляем установщик пакетов pip
.venv/bin/pip install --upgrade pip

# Устанавливаем серверные зависимости (FastAPI, Uvicorn и т.д.)
.venv/bin/pip install -r server/requirements.txt
```

### 2. Настройка сетевого интерфейса WireGuard и пересылки трафика
Чтобы сервер мог выпускать трафик телефона в интернет, нужно включить пересылку пакетов в ядре Linux. В проекте для этого уже подготовлен скрипт:

```bash
# Разрешаем запуск скрипта и выполняем его
sudo chmod +x scripts/fix-gateway-forwarding.sh
sudo ./scripts/fix-gateway-forwarding.sh
```
*Что делает этот скрипт? Включает пересылку пакетов (`ip_forward=1`), настраивает маскарадинг (NAT) и устраняет проблему зависания тяжёлых сайтов (MSS Clamping).*

### 3. Запуск Шлюза (Терминал №1)
Откройте **первое** окно терминала в папке проекта и выполните:

```bash
./scripts/start-gateway-agent.sh
```
В терминале появится надпись:
```text
Starting Gateway Agent on 127.0.0.1:8787 (unprivileged UID=... with CAP_NET_ADMIN only)...
INFO:     Uvicorn running on http://127.0.0.1:8787 (Press CTRL+C to quit)
```
Оставьте этот терминал открытым! Шлюз готов принимать команды.

### 4. Запуск Диспетчера (Терминал №2)
Откройте **второе** окно терминала в той же папке проекта и выполните:

```bash
./scripts/start-control-plane.sh
```
Вы увидите:
```text
Control Plane Host Endpoint for WireGuard: 192.168.x.x
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```
Оставьте этот терминал открытым!

### 5. Быстрая проверка здоровья серверов
Откройте третье окно терминала и проверьте, что оба сервера отвечают:

```bash
# Проверяем Шлюз:
curl http://127.0.0.1:8787/healthz
# Должен вернуть: {"status":"ok","interface":"tunnelpilot0",...}

# Проверяем Диспетчера:
curl http://127.0.0.1:8000/v1/servers
# Должен вернуть список серверов в формате JSON!
```
Серверная часть полностью готова и работает! 🎉

## Шаг 4: Подготовка смартфона Android

Чтобы установить приложение с компьютера напрямую через кабель, на смартфоне нужно один раз включить режим разработчика.

1. Откройте **«Настройки»** на телефоне.
2. Перейдите в раздел **«О телефоне»** (или «Об устройстве»).
3. Найдите строку **«Номер сборки»** (на смартфонах Xiaomi/Poco — строка **«Версия ОС»** или **«Версия MIUI»**).
4. Быстро нажмите на эту строку **7 раз подряд**. Телефон покажет всплывающее сообщение: *«Вы стали разработчиком!»*.
5. Вернитесь в главное меню настроек, найдите пункт **«Для разработчиков»** (обычно в разделе «Система» или «Расширенные настройки»).
6. Включите переключатели:
   - ✅ **Отладка по USB** (USB debugging).
   - *(Для Xiaomi/Redmi/Poco обязательно)*: ✅ **Установка через USB** (Install via USB).
7. Подключите телефон к компьютеру хорошим USB-кабелем (не только для зарядки, а для передачи данных).
8. На экране телефона появится окно: **«Разрешить отладку по USB с этого компьютера?»**. Поставьте галочку *«Всегда разрешать с этого компьютера»* и нажмите **«Разрешить»**.

## Шаг 5: Сборка и установка приложения на телефон

Вернитесь в терминал на компьютере.

### 1. Проверяем, видит ли компьютер ваш телефон:
```bash
adb devices
```
В ответ должна появиться строка с серийным номером вашего телефона и словом `device`:
```text
List of devices attached
qs65vsrseqkrxs7x    device
```
*(Если написано `unauthorized` — разблокируйте экран телефона и нажмите «Разрешить» в появившемся диалоге).*

### 2. Пробрасываем порт связи:
Если сервер запущен на этом же компьютере, выполните команду, чтобы телефон мог общаться с компьютером по локальному адресу `127.0.0.1:8000`:
```bash
adb reverse tcp:8000 tcp:8000
```

### 3. Сборка и установка:

#### На Linux / Mac / WSL:
В папке проекта выполните команду автоматической установки:
```bash
./scripts/tp-adb-cli.sh install
```
Этот скрипт сам запустит Gradle, соберёт свежий APK и установит его на ваш телефон. На экране терминала появится:
```text
BUILD SUCCESSFUL
Performing Streamed Install
Success
```

#### На чистой Windows (через PowerShell или Командную строку):
```powershell
# 1. Собираем отладочный APK-файл
.\gradlew.bat :app:assembleDebug

# 2. Устанавливаем собранный файл на телефон
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

На экране вашего смартфона появится иконка приложения **TunnelPilot**! 🚀

## Шаг 6: Первое подключение и проверка работы

Вы можете управлять приложением двумя способами: пальцем на экране телефона или через терминал с компьютера.

### Способ А: На экране телефона
1. Откройте приложение **TunnelPilot** на смартфоне.
2. Вы увидите главный экран:
   - Вверху — статус подключения (серый кружок: *Disconnected*).
   - По центру — карточки серверов (например, сервер `dev-lan-1`).
   - Кнопка режима работы (*All Apps* — весь телефон, или *Selected Apps* — только выбранные программы).
3. Нажмите большую кнопку **«Connect»** (или переключатель).
4. При первом запуске Android покажет стандартный системный запрос: **«TunnelPilot запрашивает разрешение на создание подключения VPN»**. Нажмите **ОК** (это стандартная защита Android для всех VPN).
5. Статус станет зелёным: **Connected**!
6. В строке состояния телефона появится значок ключика 🔑.

### Способ Б: Через командную строку (ADB CLI)
Разработчики TunnelPilot встроили возможность полного контроля через терминал:

```bash
# 1. Посмотреть подробный статус приложения:
./scripts/tp-adb-cli.sh status

# 2. Проверить список доступных серверов:
./scripts/tp-adb-cli.sh servers

# 3. Включить VPN:
./scripts/tp-adb-cli.sh connect

# 4. Проверить, что интернет реально идёт через туннель:
./scripts/tp-adb-cli.sh probe-http https://example.com
```

Если в ответ на `probe-http` вы видите:
`message=http_status=200 ... tx_bytes=... rx_bytes=...` — значит, пакеты успешно зашифровались телефоном, долетели до сервера, сервер открыл сайт и вернул ответ обратно!

## Полезные команды удалённого управления (ADB CLI)

Скрипт `scripts/tp-adb-cli.sh` позволяет автоматизировать всё, что умеет приложение:

| Команда | Что делает |
|---|---|
| `./scripts/tp-adb-cli.sh status` | Показывает текущий IP, состояние туннеля, счётчики переданных байт |
| `./scripts/tp-adb-cli.sh servers` | Запрашивает каталог серверов с сервера управления |
| `./scripts/tp-adb-cli.sh connect` | Запускает VPN-соединение |
| `./scripts/tp-adb-cli.sh disconnect` | Останавливает VPN-соединение |
| `./scripts/tp-adb-cli.sh rotate-key` | Безопасно меняет ключ шифрования на новый |
| `./scripts/tp-adb-cli.sh select-region <код>` | Выбирает предпочитаемый регион (например `eu-west`) |
| `./scripts/tp-adb-cli.sh select-server <id>` | Выбирает конкретный сервер (например `dev-lan-1`) |
| `./scripts/tp-adb-cli.sh migrate-server <id>` | Переносит ваше устройство на другой сервер |
| `./scripts/tp-adb-cli.sh set-mode SELECTED_APPS` | Включает режим раздельного туннелирования |
| `./scripts/tp-adb-cli.sh set-apps <пакеты>` | Указывает список пакетов через запятую |
| `./scripts/tp-adb-cli.sh apply-routing` | Применяет изменения маршрутизации на лету |
| `./scripts/tp-adb-cli.sh revoke` | Отзывает регистрацию устройства на сервере |

## Частые вопросы и решение проблем («Что делать, если...»)

### 1. `adb devices` пишет `unauthorized` или список пуст
* **Причина:** телефон не распознал компьютер или кабель используется только для зарядки.
* **Решение:** разблокируйте экран смартфона. Если появилось всплывающее окно «Разрешить отладку?», нажмите «ОК». Если окно не появляется, переподключите кабель или попробуйте другой порт USB. В меню разработчика выключите и снова включите «Отладка по USB».

### 2. Ошибка `Failed to connect to /127.0.0.1:8000`
* **Причина:** телефон пытается постучаться на локальный сервер Диспетчера, но порт не проброшен или сервер выключен.
* **Решение:**
  1. Убедитесь, что во втором терминале запущен `./scripts/start-control-plane.sh`.
  2. Выполните команду `adb reverse tcp:8000 tcp:8000`.

### 3. VPN пишет «Connected», но сайты в браузере не открываются
* **Причина:** в ядре Linux на сервере не включена пересылка пакетов (forwarding) или не настроен NAT-маскарадинг.
* **Решение:** выполните на сервере команду:
  ```bash
  sudo ./scripts/fix-gateway-forwarding.sh
  ```
  Она включит пересылку `net.ipv4.ip_forward=1` и настроит правила межсетевого экрана `iptables`.

### 4. Ошибка при ротации ключа: `Disconnect the VPN before rotating the client key`
* **Причина:** в целях безопасности протокола WireGuard нельзя подменять активный ключ прямо во время идущей передачи данных.
* **Решение:** сначала отключите туннель (`./scripts/tp-adb-cli.sh disconnect`), затем выполните ротацию (`./scripts/tp-adb-cli.sh rotate-key`), и снова подключитесь (`connect`).

### 5. Как собрать релизную сборку (Release APK)?
В релизной сборке автоматически удаляются отладочные интерфейсы и включается оптимизация кода ProGuard/R8:
```bash
./gradlew :app:assembleRelease
```
Готовый установочный файл появится по пути:
`app/build/outputs/apk/release/app-release-unsigned.apk`.
